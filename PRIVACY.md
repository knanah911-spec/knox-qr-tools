# Privacy Policy — KNOX QR Tools

**Last updated: 17 October 2026**

## What the app does
KNOX QR Tools creates QR codes from text/URLs and reads QR codes from images selected by the user.

## Data handling
- The URL entered to create a QR code is processed in the browser.
- Images selected for QR reading are processed locally in the browser using JavaScript.
- This project does not include an app-specific backend, account system, analytics, advertising, or intentional collection of QR contents.
- If a QR code contains sensitive information, do not share the generated image or decoded text with others.

## Third-party resources and hosting logs
The current app loads QR libraries from public CDNs (cdnjs, jsDelivr, or unpkg). Those providers may receive ordinary connection information such as your IP address and browser request metadata when a library is requested. GitHub Pages or another hosting provider may also process standard server logs.

## Internet requirement
Because the libraries are loaded from CDNs, an internet connection is required for QR generation and decoding to work. This project version does not bundle those libraries inside the HTML file.

## Changes
This policy may be updated when the project changes.
